# Racing Car Game

A simple, responsive racing car game built with HTML, CSS, and JavaScript.

![Game Screenshot](./Screenshot%202026-04-25%20at%2016.49.39.png)

## Overview

This is a lightweight browser game where you control a car to avoid obstacles and score points. It's built using plain HTML, CSS, and JavaScript so you can run it locally without any build steps.

## Features

- Simple, responsive gameplay
- Keyboard controls (arrow keys / A & D)
- Collision detection and scoring
- Easy to read and extend code — great for learning JavaScript game basics

## How to play

1. Open `index.html` in your web browser (Chrome, Firefox, Edge, Safari).
2. Use Left / Right arrow keys or A and D to move the car.
3. Avoid incoming obstacles. Each successful dodge increases your score.
4. The game ends when your car collides with an obstacle — refresh to play again.

## Installation / Run locally

1. Clone the repository:

   git clone https://github.com/BinaryVortex/Racing-Car-Game.git

2. Open the project folder and double-click `index.html`, or serve the folder with a static server (optional):

   npx http-server .

3. Play in your browser.

## Development

- Code is written in plain HTML, CSS and JavaScript. Look for `index.html`, `styles.css`, and `script.js` (or similar) in the repository root.
- Feel free to fork and add features like levels, mobile controls, or sound effects.
